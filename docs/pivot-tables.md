# Pivot tables

A pivot table is a definition that tells Excel how to aggregate a cached copy of source
data. Aid.Xlsx reads and edits pivot table definitions and their caches, creates new pivot
tables from a worksheet range or an [Excel table](tables-and-data-import.md), and writes
everything back. It does not calculate or draw the rendered pivot cells; Excel produces
them when the pivot refreshes.

## How pivot tables are represented

An `IXlsxPivotTable` has a name, a target cell, four field areas (`RowLabels`,
`ColumnLabels`, `ReportFilters`, `Values`), layout and style settings, and an
`IXlsxPivotCache`. The cache holds a snapshot of the source: `FieldNames` lists the cache
fields and the cached records are written into the file. The source is chosen when the
cache is created (a range or a table) and is preserved by the reader, but the public API
does not expose a source object; use `FieldNames` to inspect the cache.

Distinct cached values are stored in shared items inside the cache definition. That part
of the model is internal, so treat the cache as read-only data you can refresh, not as a
collection you edit value by value.

When a workbook is loaded, the pivot table definition and cache are restored, and the
rendered cells in the pivot area are cleared. They are a projection that Excel rebuilds.
When the workbook is saved, the cache definition, cache records and pivot definition are
written back, but the rendered values are not regenerated by the library.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.Workbooks;

using var workbook = new XlsxWorkbook("report.xlsx");
var sheet = workbook.Worksheet("Report");

foreach (IXlsxPivotTable pivot in sheet.PivotTables)
{
    Console.WriteLine(pivot.Name);
    Console.WriteLine(string.Join(", ", pivot.PivotCache.FieldNames));
}
```

`sheet.PivotTables` enumerates the pivots on one worksheet. `workbook.PivotCaches`
enumerates the caches of the whole workbook; caches are shared between pivot tables that
use the same data.

## Create a pivot table from a range

The source range must include the header row; the first row becomes the cache field names.
If headers repeat, the cache renames the later duplicates (`Name`, `Name2`, ...). The
target cell is the top-left corner of the pivot table and may be on another worksheet.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.PivotTables.Areas;
using Aid.Xlsx.Model.PivotTables.PivotValues;
using Aid.Xlsx.Model.Workbooks;

using var workbook = new XlsxWorkbook();
var data = workbook.Worksheets.Add("Data");

var rows = new[]
{
    new object[] { "Month", "Product", "Units", "Revenue" },
    new object[] { "Jan", "Pears", 12, 60.0 },
    new object[] { "Jan", "Apples", 8, 32.0 },
    new object[] { "Feb", "Pears", 20, 100.0 },
};
var table = data.Cell("A1").InsertData(rows).CreateTable("SalesTable");

var report = workbook.Worksheets.Add("Report");
IXlsxPivotTable pivot = table.CreatePivotTable(report.Cell("A3"), "SalesPivot");

pivot.RowLabels.Add("Product");
pivot.ColumnLabels.Add("Month");
pivot.Values.Add("Units", "Units sold").SetSummaryFormula(XlsxPivotSummary.Sum);
pivot.Values.Add("Revenue", "Revenue").SetSummaryFormula(XlsxPivotSummary.Sum)
    .NumberFormat.SetFormat("#,##0.00");
pivot.Theme = XlsxPivotTableTheme.PivotStyleMedium2;
pivot.SetLayout(XlsxPivotLayout.Tabular);

workbook.SaveAs("sales-pivot.xlsx");
```

Adding a second field to `Values` automatically adds the internal data-field placeholder to
the column axis, which is what Excel expects for several value fields. Pivot table names
should be unique; adding a duplicate name to the same worksheet throws
`ArgumentException`.

A newly created cache is written with refresh-on-load enabled, so Excel rebuilds the
pivot when it opens the file. The library writes no output cells, so Excel must refresh
before values appear in the target area.

### Create from a table or reuse a cache

`table.CreatePivotTable(targetCell, name)` records a table source instead of an address
range. The same `CreatePivotTable` method is available on a range and on a table.

```csharp
var data = workbook.Worksheet("Data");
var report = workbook.Worksheet("Report");
var table = data.Table("SalesTable");

var pivot = table.CreatePivotTable(report.Cell("A3"), "ByProduct");
```

To share one cache between pivots, create the cache once and pass it to each pivot. The
cache reads its source when it is created; call `Refresh()` after the source changes.

```csharp
var cache = workbook.PivotCaches.Add(data.Range("A1:D4"));
var first = report.PivotTables.Add("ByProduct", report.Cell("A3"), cache);

var secondSheet = workbook.Worksheets.Add("ByMonth");
var second = secondSheet.PivotTables.Add("ByMonth", secondSheet.Cell("A3"), cache);
second.RowLabels.Add("Month");
```

`PivotTables.Add` also accepts an `IXlsxRange` or an `IXlsxTable`. When the range exactly
matches an Excel table's area, the cache records the table as its source; otherwise it
records the address. Two pivots created from the same area reuse the existing cache.

## Fields on axes

`RowLabels`, `ColumnLabels` and `ReportFilters` all return `IXlsxPivotFields`. `Add`
accepts a cache field name and an optional custom name. `Get`, `Contains`, `Remove`,
`Clear` and `IndexOf` manage the collection, and a field reports whether it is on a row
axis, a column axis, or a page filter.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.PivotTables.Areas;

var pivot = workbook.Worksheet("Report").PivotTable("SalesPivot");
IXlsxPivotField product = pivot.RowLabels.Add("Product");

product.SetSort(XlsxPivotSortType.Descending);
product.SetRepeatItemLabels();
product.SetSubtotalsAtTop(false);

var month = pivot.ReportFilters.Add("Month");
month.AddSelectedValue("Jan");
month.SetCollapsed();

Console.WriteLine(product.IsOnRowAxis);   // true
Console.WriteLine(month.IsInFilterList);  // true
```

`AddSelectedValue` and `AddSelectedValues` select page-filter items; `SelectedValues`
returns the current selection. `SetCollapsed` collapses items, and `Offset` returns the
field's index in the pivot table's field collection (or `-2` for the data field). These
setters update the field definition, not the rendered cells.

Field options include `SetLayout(XlsxPivotLayout)`, `SetInsertBlankLines`,
`SetInsertPageBreaks`, `SetShowBlankItems`, `SetIncludeNewItemsInFilter` and
`SetCustomName`. `Compact` and `Outline` are settable properties.

## Data fields, aggregation and formats

`pivot.Values.Add(sourceName)` adds a data field with the source name as its caption;
`Add(sourceName, customName)` gives it a distinct caption. Give the same source different
custom names when you add it twice, so Excel can distinguish the value fields.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.PivotTables.PivotValues;

var revenue = pivot.Values.Add("Revenue", "Revenue");
revenue.SetSummaryFormula(XlsxPivotSummary.Sum);
revenue.NumberFormat.SetFormat("#,##0.00");
revenue.SetCalculation(XlsxPivotCalculation.PercentageOfColumn);
revenue.SetBaseFieldName("Month");
revenue.SetBaseItemValue("Jan");
```

`IXlsxPivotValue.NumberFormat` returns an `IXlsxPivotValueFormat` with two ways to set the
number format: `SetFormat(string)` for an Excel format code, and
`SetNumberFormatId(int)` for a predefined format id. `SetNumberFormatId` raises
`ArgumentOutOfRangeException` for a non-predefined id.

| `XlsxPivotSummary` | Aggregation |
| --- | --- |
| `Sum`, `Count`, `Average` | Sum, count of values, arithmetic mean |
| `Minimum`, `Maximum`, `Product` | Smallest, largest, product |
| `CountNumbers`, `StandardDeviation`, `Variance` | Count, sample deviation, sample variance |
| `PopulationStandardDeviation`, `PopulationVariance` | Population deviation and variance |

| `XlsxPivotCalculation` | Show values as |
| --- | --- |
| `Normal` | The aggregated value |
| `DifferenceFrom`, `PercentageDifferenceFrom` | Difference from a base item |
| `PercentageOf` | Percentage of a base item |
| `RunningTotal` | Running total in a field |
| `PercentageOfRow`, `PercentageOfColumn`, `PercentageOfTotal` | Percent of row, column or total |
| `Index` | Relative importance of a value |

Calculations that need a reference item use `BaseFieldName` and `BaseItemValue`, or the
fluent helpers. `ShowAsNormal`, `ShowAsIndex`, `ShowAsPercentageOfTotal`,
`ShowAsPercentageOfRow`, `ShowAsPercentageOfColumn` and `ShowAsRunningTotalIn` set the
common cases. `ShowAsDifferenceFrom`, `ShowAsPercentageDifferenceFrom` and
`ShowAsPercentageFrom` return an `IXlsxPivotValueCombination` that accepts `And`,
`AndNext` or `AndPrevious` to choose the reference item:

```csharp
pivot.Values.Add("Revenue", "Growth")
    .ShowAsDifferenceFrom("Month")
    .AndPrevious();
```

`SummaryFormula` and `Calculation` can also be assigned directly, and `CustomName` is
settable after the field is added.

## Layout, theme and style

Whole-table options control the pivot's appearance and the parts Excel renders:

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.PivotTables.Areas;

pivot.Theme = XlsxPivotTableTheme.PivotStyleLight16;
pivot.SetLayout(XlsxPivotLayout.Outline);
pivot.ClassicPivotTableLayout = false;
pivot.ShowGrandTotalsRows = true;
pivot.ShowGrandTotalsColumns = false;
pivot.ShowRowHeaders = true;
pivot.ShowColumnHeaders = true;
pivot.ShowRowStripes = true;
pivot.ShowValuesRow = true;
pivot.RowHeaderCaption = "Product";
pivot.ColumnHeaderCaption = "Month";
```

`Theme` uses the `PivotStyleLight1`–`PivotStyleLight28`, `PivotStyleMedium1`–
`PivotStyleMedium28` and `PivotStyleDark1`–`PivotStyleDark28` constants, or `None` for no
theme. `Layout` is `Outline`, `Tabular` or `Compact`. `Subtotals` accepts
`XlsxPivotSubtotals.AtTop`, `AtBottom` or `DoNotShow`; per-field subtotals use
`AddSubtotal`:

```csharp
pivot.Subtotals = XlsxPivotSubtotals.AtTop;
pivot.RowLabels.Get("Product").AddSubtotal(XlsxSubtotalFunction.Sum);
pivot.RowLabels.Get("Product").AddSubtotal(XlsxSubtotalFunction.Count);
```

`FilterAreaOrder` is `DownThenOver` or `OverThenDown`, and `FilterFieldsPageWrap` limits
how many page fields are placed before a wrap.

Differential styles apply on top of the theme. Start from a cell style, adjust it, and
assign it to the pivot part:

```csharp
var emphasis = pivot.TargetCell.Style;
emphasis.Font.Bold = true;

pivot.StyleFormats.RowGrandTotalFormats
    .ForElement(XlsxPivotStyleFormatElement.Data)
    .Style = emphasis;

pivot.RowLabels.Get("Product").StyleFormats.Label.Style = emphasis;
```

`StyleFormats` exists on the pivot table and on each field. The pivot table exposes
`RowGrandTotalFormats` and `ColumnGrandTotalFormats`; `ForElement` takes `Label`, `Data`
or `All` (not `None`). Field style formats expose `Header`, `Label`, `Subtotal` and
`DataValuesFormat`. Styles are differential: Excel composes every overlapping format, and
the library stores them in the file without rendering the result.

## Refresh the cache and preserve the file

A cache is a snapshot. After changing the source cells, call `Refresh()` to re-read the
range or table and rebuild the cached fields. The method throws `InvalidReferenceException`
when the source cannot be found, and can throw `NotImplementedException` for a cache whose
source is an external connection.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.Workbooks;

using var workbook = new XlsxWorkbook("report.xlsx");
var pivot = workbook.Worksheet("Report").PivotTable("SalesPivot");

pivot.PivotCache.Refresh();
workbook.SaveAs("report-updated.xlsx");
```

| `IXlsxPivotCache` member | Behavior |
| --- | --- |
| `FieldNames` | Unique cache field names in source order |
| `Refresh()` | Re-reads the source and updates dependent pivot fields |
| `SaveSourceData` | Default `true`; stores cache records in the file |
| `ItemsToRetainPerField` | `Automatic`, `None` or `Max`; controls unused shared items |
| `RefreshDataOnOpen` | Refresh-on-open setting; see the note below on persistence |

New caches are saved with refresh-on-load enabled. For a cache loaded from an existing
file, the current writer keeps the refresh setting that the original definition had and
does not rewrite it from `RefreshDataOnOpen`; set the option in Excel if the saved pivot
must refresh automatically.

The following parts survive a load/save round-trip: the cache definition and records, the
pivot definition and field axes, the selected filter items, layout attributes, themes and
differential style formats. Pivot tables are never recalculated by Aid.Xlsx, and the
rendered cells are cleared on load, so the file shows an empty pivot area until Excel
refreshes it. If `SaveSourceData` is `false`, Excel must be able to reach the source to
show values.

Caches with an external workbook, a data connection or a consolidation source are
preserved as definitions, but they cannot be refreshed locally. Caches whose source was a
named range cannot be resolved either; the current implementation only resolves table and
address sources.

## Read, edit and delete existing pivot tables

Load a workbook, find a pivot by name, and change its definition. All field and layout
settings described above work on existing pivot tables.

```csharp
using Aid.Xlsx.Model.PivotTables;
using Aid.Xlsx.Model.Workbooks;

using var workbook = new XlsxWorkbook("existing.xlsx");
var report = workbook.Worksheet("Report");

if (report.PivotTables.Contains("SalesPivot"))
{
    var pivot = report.PivotTable("SalesPivot");
    pivot.Theme = XlsxPivotTableTheme.PivotStyleDark3;
    pivot.SetLayout(XlsxPivotLayout.Compact);
    pivot.Values.Get("Revenue").NumberFormat.SetFormat("#,##0");
}
```

`pivot.CopyTo(targetCell)` copies the pivot definition to another cell and shares the
cache. `pivot.TargetCell = report.Cell("A20")` moves the target cell. Both change only the
definition; the old rendered cells are not moved or cleared.

`report.PivotTables.Delete("SalesPivot")` and `DeleteAll()` remove pivots from the
in-memory collection. Do this for pivots created in the current session. A pivot table
loaded from a file is linked through a `pivotTable` part that the library does not unlink,
so that pivot can remain in the saved package; remove loaded pivot tables in Excel
instead. Pivot caches cannot be removed directly through `workbook.PivotCaches`; a cache
that no current pivot references is not written on save.

When editing an existing pivot, keep the source range or table unchanged unless you also
refresh the cache. A changed header or a removed column makes the pivot fields refer to
missing cache fields, and Excel may repair the file. Refresh the cache after changing the
source, then verify the pivot in Excel before distributing the workbook.
